Install 303 Circuit Model

303 Circuit Model is a free acid bass synth, modelled part by part from the original 1982 bass line circuit. This page shows you how to put it into your music software, one small step at a time. You don’t need any experience.

Want to hear it first? It runs in your web browser, no install needed.

Try it in the browser

Before you start

Music software is often called a DAW (short for digital audio workstation). Ableton Live, Logic Pro, FL Studio, Reaper, Bitwig, Cubase and GarageBand are all DAWs. A plug-in is an extra instrument you add to your DAW.

  • Mac (Apple Silicon and Intel, macOS 11 or later): VST3 and AU. AU is the kind Logic Pro and GarageBand use.
  • Windows 10 or 11, 64-bit: VST3.
  • Linux (x86_64): VST3.

No accounts, no tracking. Your presets stay on your computer.

Pick your computer

Mac install command

curl -fsSL https://github.com/johnnyhawk02/tb303-circuit-model/releases/latest/download/install.sh | bash

  1. Open Terminal. Press Cmd + Space, type Terminal, press Return.

    A window with a blinking cursor opens. That is all Terminal is: a place to type commands.

    Terminal
    ~ %

  2. Click Copy on the install command above.

  3. Click in the Terminal window, then paste with Cmd + V.

  4. Press Return.

    You’ll see “Downloading 303 Circuit Model...” and a progress bar. Nothing needs typing. No password is asked for.

  5. When it says Done., close Terminal.

    Terminal
    Downloading 303 Circuit Model...
    Done.
    Rescan plug-ins in your DAW

  6. Open your music software and rescan plug-ins (see Find it in your DAW below).

What this does. It downloads the plug-in and copies two files into your own Library: 303 Circuit Model.vst3 into ~/Library/Audio/Plug-Ins/VST3 and 303 Circuit Model.component into ~/Library/Audio/Plug-Ins/Components. Nothing else on your Mac is changed. Running it again is safe; it just updates to the newest version.

Windows install command

irm https://github.com/johnnyhawk02/tb303-circuit-model/releases/latest/download/install.ps1 | iex

  1. Open PowerShell. Click Start, type PowerShell, press Enter.

    A blue or black window opens. Don’t pick “Run as administrator”; the installer asks for permission itself.

    Windows PowerShell– □ ×
    PS C:\Users\you>

  2. Click Copy on the Windows command above.

  3. Right-click inside the PowerShell window to paste (or press Ctrl + V).

  4. Press Enter.

  5. When Windows asks “Do you want to allow this app to make changes to your device?”, click Yes.

  6. When it says Done., close PowerShell and rescan plug-ins in your DAW (see Find it in your DAW below).

What this does. It downloads the plug-in and copies 303 Circuit Model.vst3 into C:\Program Files\Common Files\VST3, the folder every DAW looks in. That folder is shared by the whole computer, which is why Windows asks for permission once. Running it again is safe; it just updates to the newest version.

The plug-in’s screen needs the Microsoft Edge WebView2 Runtime. Windows 11 and up-to-date Windows 10 already have it. If yours doesn’t, the installer tells you, and you can get it free from Microsoft’s WebView2 page (choose the Evergreen Bootstrapper).

Linux install command

curl -fsSL https://github.com/johnnyhawk02/tb303-circuit-model/releases/latest/download/install.sh | bash

  1. Open your terminal app. On many systems Ctrl + Alt + T opens it.

  2. Click Copy above, then paste into the terminal with Ctrl + Shift + V.

  3. Press Enter.

  4. If it says WebKitGTK is missing, run the command it prints, then you’re set. When it says Done., rescan plug-ins in your DAW.

What this does. It downloads the plug-in and copies 303 Circuit Model.vst3 into ~/.vst3. Running it again is safe; it just updates to the newest version.

The plug-in’s screen needs WebKitGTK 4.1. If it’s missing, the installer says so and prints the command for your system:

  • Debian / Ubuntu: sudo apt install libwebkit2gtk-4.1-0
  • Fedora: sudo dnf install webkit2gtk4.1
  • Arch: sudo pacman -S webkit2gtk-4.1

Why a command, not a normal download?

The plug-in is free, and I haven’t paid Apple’s yearly fee to have it notarised. A Mac blocks un-notarised plug-ins downloaded in a web browser, and says they are “damaged”. Downloaded with the command, it isn’t blocked.

The command only downloads the plug-in and copies it into the plug-in folder. Nothing else on your computer is changed.

Find it in your DAW

  • Ableton LiveSettings > Plug-ins, turn on “Use VST3 Plug-in System Folders”, click Rescan. It’s under Plug-ins > 303 Circuit.
  • Logic Pro / GarageBand(Mac) It appears under Audio Units > 303 Circuit > 303 Circuit Model. If not, restart Logic.
  • FL StudioOptions > Manage plugins > Find plugins.
  • ReaperOptions > Preferences > Plug-ins > VST > Re-scan.
  • Bitwig, Cubase, Studio One and othersRescan or restart; it’s listed as “303 Circuit Model” by “303 Circuit”.

Add it to an instrument track. Press play in the DAW: the plug-in follows the DAW’s play, stop and tempo.

For the controls, patterns, effects, MIDI and keyboard shortcuts, read the 303 Circuit Model guide.

Updating

Run the same install command again. It replaces the plug-in with the newest version.

Uninstalling

Mac and Linux

Open Terminal, paste this and press Return (Enter on Linux):

curl -fsSL https://github.com/johnnyhawk02/tb303-circuit-model/releases/latest/download/install.sh | bash -s -- --uninstall

Windows

In File Explorer, delete this folder. Windows asks for permission; click Continue.

C:\Program Files\Common Files\VST3\303 Circuit Model.vst3

Your presets

Your presets are kept in the folder below. To remove them too, delete it:

  • Mac: ~/Library/Application Support/303 Circuit Model
  • Windows: %APPDATA%\303 Circuit Model
  • Linux: ~/.config/303 Circuit Model

Trouble?

“command not found: curl” (very rare, Linux)

Install curl with your system’s package manager, then run the install command again.

Nothing shows up in my DAW

Make sure your DAW is 64-bit and scans the standard VST3 folder, then rescan. If it still isn’t there, restart the DAW.

The plug-in window is blank

Windows: install the WebView2 Runtime (Evergreen Bootstrapper). Linux: install WebKitGTK 4.1 (the commands are in the Linux tab above).

My Mac says it’s damaged

You downloaded the zip in a web browser. Use the Terminal command instead; it isn’t blocked.
