# Johnny Hawk Audio

Home page for Johnny Hawk Audio: browser instruments and plugins. One static `index.html`, ready for GitHub Pages.

## 3D

`/assets/depth.js` folds the white bands in as you scroll and tilts the product cards toward the mouse (off when reduced motion is on).

It is built from `src/depth.js`. After editing there:

```sh
npm install
npm run build
```

Commit the rebuilt `assets/depth.js`; GitHub Pages serves it as it is.
