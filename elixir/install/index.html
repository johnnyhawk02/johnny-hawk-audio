Elixir Desktop · free plug-in

Install Elixir Desktop

A six-voice drum machine built on the LXR-02 engine, with step sequencers on every control. Load it in your music software as a VST3, Audio Unit, CLAP or LV2 plug-in, or run it as a standalone app. Free and open source.

Try it in the browser first

The browser version is for desktop computers only. It doesn’t work on phones or tablets.

Download Elixir Desktop 1.1.1Install steps
MacApple Silicon + Intel, macOS 11+

Elixir is free, and I don’t have an Apple Developer account, so the Mac version isn’t signed. If you download it in your browser, macOS will block it. This one command installs it so macOS won’t complain. Pick what you want:

curl -fsSL https://raw.githubusercontent.com/johnnyhawk02/elixir-desktop-vst/main/install-mac.sh | bash
  1. Press ⌘ + Space, type Terminal and press Return. A window with text opens.
  2. Click Copy above.
  3. Click inside the Terminal window, press ⌘ + V to paste, then press Return.
  4. Wait until it says Done. It takes about a minute.
  5. Restart your music software and rescan plugins. The app is in your Applications folder.

What’s inside

  • Voices6: three drum/tom, snare/clap, cymbal, hi-hat
  • Kits28 bundled, plus any LXR .SND file
  • FX busDistortion, ring mod, compressor, delay
  • Routing6 × 6 crossfeed patchbay
  • Accuracy176 million samples checked against the firmware, all identical
  • FormatsVST3, Audio Unit, CLAP, LV2 and a standalone app
