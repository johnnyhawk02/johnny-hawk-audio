FILTH · free plug-in

Install FILTH

FILTH is now a free plug-in too: VST3 for Mac (Apple Silicon and Intel), Windows and Linux, AU for Mac, and a standalone app. It has the same sound and the same 3D panel as the browser version. Its engine is a C++ port that gives exactly the same samples.

Want to hear it first? It runs in your web browser, no install needed.

Play in the browser

Download and install

Download the zip for your computer, or copy the one-line install command and paste it into a terminal. The command downloads the newest version and puts the plug-in in the right folder.

Your computer

macOS

Apple Silicon and Intel · VST3, AU and app

VST3 zip AU Logic, GarageBand App zip

Install VST3 and AU together (Terminal)

curl -fsSL -o /tmp/FILTH-VST3.zip https://github.com/johnnyhawk02/polivoks/releases/latest/download/FILTH-VST3-macOS.zip && curl -fsSL -o /tmp/FILTH-AU.zip https://github.com/johnnyhawk02/polivoks/releases/latest/download/FILTH-AU-macOS.zip && mkdir -p ~/Library/Audio/Plug-Ins/VST3 ~/Library/Audio/Plug-Ins/Components && rm -rf ~/Library/Audio/Plug-Ins/VST3/FILTH.vst3 ~/Library/Audio/Plug-Ins/Components/FILTH.component && unzip -oq /tmp/FILTH-VST3.zip -d ~/Library/Audio/Plug-Ins/VST3 && unzip -oq /tmp/FILTH-AU.zip -d ~/Library/Audio/Plug-Ins/Components && xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/FILTH.vst3 ~/Library/Audio/Plug-Ins/Components/FILTH.component 2>/dev/null; killall -9 AudioComponentRegistrar 2>/dev/null; echo "FILTH installed"

Open Terminal (Cmd + Space, type Terminal), paste, press Return. It ends with “FILTH installed”.

Install the VST3 (PowerShell, as administrator)

curl.exe -fsSL -o "$env:TEMP\FILTH-VST3.zip" https://github.com/johnnyhawk02/polivoks/releases/latest/download/FILTH-VST3-Windows.zip; Remove-Item -Recurse -Force "$env:CommonProgramFiles\VST3\FILTH.vst3" -ErrorAction SilentlyContinue; Expand-Archive -Force "$env:TEMP\FILTH-VST3.zip" "$env:CommonProgramFiles\VST3"; "FILTH installed"

Click Start, type PowerShell, right-click it and choose Run as administrator (the VST3 folder is in Program Files). Paste, press Enter. It ends with “FILTH installed”.

curl -fsSL -o /tmp/FILTH-VST3.zip https://github.com/johnnyhawk02/polivoks/releases/latest/download/FILTH-VST3-Linux.zip && mkdir -p ~/.vst3 && rm -rf ~/.vst3/FILTH.vst3 && unzip -oq /tmp/FILTH-VST3.zip -d ~/.vst3 && echo "FILTH installed"

Open a terminal (often Ctrl + Alt + T), paste with Ctrl + Shift + V, press Enter. It ends with “FILTH installed”.

Then rescan in your DAW

After installing, your music software has to rescan its plug-ins before it sees FILTH. It appears as an instrument by Johnny Hawk. Put it on an instrument track.

  • Ableton LiveSettings > Plug-ins, turn on “Use VST3 Plug-in System Folders”, click Rescan.
  • Logic Pro / GarageBand(Mac) It appears under Audio Units > Johnny Hawk. If not, restart Logic.
  • FL StudioOptions > Manage plugins > Find plugins.
  • ReaperOptions > Preferences > Plug-ins > VST > Re-scan.
  • Bitwig, Cubase, Studio One and othersRescan plug-ins or restart the DAW.

Plug-in folders, if you’re copying by hand or pointing your DAW at them:

  • macOS~/Library/Audio/Plug-Ins/VST3 and ~/Library/Audio/Plug-Ins/Components
  • WindowsC:\Program Files\Common Files\VST3
  • Linux~/.vst3

Unsigned builds

FILTH isn’t signed by Apple or Microsoft, so your computer may warn you the first time. Here’s what to do.

macOS

The plug-in isn’t notarised by Apple. The curl command above already clears the quarantine flag. If you download the zip in a browser instead, unzip it, move the plug-in into the folder, and run this in Terminal:

xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/FILTH.vst3

and the same for Components/FILTH.component:

xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/FILTH.component

Otherwise macOS says the plug-in “is damaged” or “can’t be opened”. For the app, right-click it and choose Open the first time.

Windows

The app isn’t code-signed, so SmartScreen may show “Windows protected your PC”. Click More info, then Run anyway. The VST3 loads in the DAW without that warning.

It needs the Microsoft Edge WebView2 runtime, which comes with Windows 10 and 11.

Linux

Needs WebKitGTK 4.1 and GTK 3. On Ubuntu 22.04 or newer:

sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0

In your DAW

  • AutomationAll 55 panel controls can be automated from the DAW.
  • MIDIWorks as on the web version: pitch bend, mod wheel and sustain.
  • Tempo and transportThe DAW’s tempo and transport drive the sequencer and the synced echo.
  • PresetsShared between plug-in instances.
  • Latency128 samples, reported to the DAW so it is compensated.

Updating and trouble

To update, run the same install command again. It replaces FILTH with the newest version.

Nothing shows up in my DAW

Check the plug-in is in the folder listed above, then rescan. If it still isn’t there, restart the DAW.

My Mac says it “is damaged”

You downloaded the zip in a browser. Use the Terminal command instead, or run the xattr commands in Unsigned builds.

The plug-in window is blank (Linux)

Install WebKitGTK 4.1 and GTK 3: sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0.
