FM/DM · free plug-in

Install FM/DM

FM/DM is a free six-voice FM drum machine. It comes as a VST3 / AU plug-in and as a standalone app. This page shows you how to put it on your computer, one small step at a time. You don’t need any experience.

Want to hear it first? It runs in your web browser, no install needed.

Try it in the browser

Before you start

Music software is often called a DAW (short for digital audio workstation). Ableton Live, Logic Pro, FL Studio, Reaper, Bitwig, Cubase and GarageBand are all DAWs. A plug-in is an extra instrument you add to your DAW. FM/DM also installs as an app, so you can play it without a DAW.

  • Mac (Apple Silicon and Intel, macOS 10.13 or later): VST3, AU and the app. AU is the kind Logic Pro and GarageBand use.
  • Windows 10 or 11, 64-bit: VST3 and the app.
  • Linux (64-bit x86, built on Ubuntu 22.04, so most distributions from 2022 on): VST3 and the app.

Pick your computer

Mac install command

curl -fsSL https://github.com/johnnyhawk02/fm-drum-machine/releases/download/plugin-latest/install.sh | sh

  1. Open Terminal. Press Cmd + Space, type Terminal, press Return.

    A window with a blinking cursor opens. That is all Terminal is: a place to type commands.

    Terminal
    ~ %

  2. Click Copy on the install command above.

  3. Click in the Terminal window, then paste with Cmd + V.

  4. Press Return, and wait for it to finish.

  5. Restart your music software, or rescan plug-ins (see Find it in your DAW below). It’s listed as an instrument called fm-dm.

What this does. It downloads FM/DM and copies the VST3 and AU plug-ins into ~/Library/Audio/Plug-Ins, and the app into ~/Applications. Running it again is safe; it just updates to the newest version.

Windows install command

irm https://github.com/johnnyhawk02/fm-drum-machine/releases/download/plugin-latest/install.ps1 | iex

  1. Open PowerShell. Click Start, type PowerShell, press Enter.

    A blue or black window opens. You don’t need “Run as administrator”.

    Windows PowerShell– □ ×
    PS C:\Users\you>

  2. Click Copy on the Windows command above.

  3. Right-click inside the PowerShell window to paste (or press Ctrl + V).

  4. Press Enter, and wait for it to finish.

  5. Close PowerShell and rescan plug-ins in your DAW (see Find it in your DAW below). The app is in your Start menu as fm-dm.

What this does. It downloads FM/DM, copies the VST3 into %LOCALAPPDATA%\Programs\Common\VST3 and the app into %LOCALAPPDATA%\Programs\fm-dm, and adds the app to the Start menu. These are your own folders, so no admin permission is needed. Running it again is safe; it just updates to the newest version.

If your DAW doesn’t find it, add %LOCALAPPDATA%\Programs\Common\VST3 to the DAW’s VST3 folders and rescan.

The screen uses Microsoft Edge WebView2, which Windows already includes.

Linux install command

curl -fsSL https://github.com/johnnyhawk02/fm-drum-machine/releases/download/plugin-latest/install.sh | sh

  1. Open your terminal app. On many systems Ctrl + Alt + T opens it.

  2. Click Copy above, then paste into the terminal with Ctrl + Shift + V.

  3. Press Enter, and wait for it to finish.

  4. Rescan plug-ins in your DAW, or run the app with ~/.local/bin/fm-dm.

What this does. It downloads FM/DM and copies the VST3 into ~/.vst3 and the app to ~/.local/bin/fm-dm. Running it again is safe; it just updates to the newest version.

The screen needs WebKitGTK 4.1. On Debian or Ubuntu, install it with sudo apt install libwebkit2gtk-4.1-0.

Rather not use a terminal?

Download the zip for your computer, unzip it, and copy the plug-in into your plug-in folder yourself.

Mac zipVST3, AU, app Windows zipVST3, app Linux zipVST3, app

On a Mac, a zip downloaded in a web browser is quarantined. If macOS says the plug-in “can’t be opened”, paste this into Terminal and press Return. The terminal install does this for you.

xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/fm-dm.vst3 ~/Library/Audio/Plug-Ins/Components/fm-dm.component

Find it in your DAW

  • Ableton LiveSettings > Plug-ins, turn on “Use VST3 Plug-in System Folders”, click Rescan.
  • Logic Pro / GarageBand(Mac) It appears under Audio Units. If not, restart Logic.
  • FL StudioOptions > Manage plugins > Find plugins.
  • ReaperOptions > Preferences > Plug-ins > VST > Re-scan.
  • Bitwig, Cubase, Studio One and othersRescan or restart; it’s listed as an instrument called “fm-dm”.

Add it to an instrument track.

Using it

  • Tempo and playThe plug-in has no play button. Your DAW’s transport starts and stops it, and it follows the DAW tempo. In the standalone app, press space to play and stop.
  • MIDI notesGeneral MIDI drum notes play the drums (36 kick, 38 snare, 42 closed hat, 46 open hat, 49 cymbal, toms for drum 2 and drum 3). From note 60 (C3 in most DAWs) upwards, each run of six notes plays the six drums in order.
  • PresetsPresets made in the web version load in the plug-in, and presets made in the plug-in load in the web version.

For the screen, randomise, keyboard shortcuts and MIDI CCs, read the FM/DM guide.

Updating

Run the same install command again. It replaces FM/DM with the newest version.

Trouble?

Nothing shows up in my DAW

Make sure your DAW is 64-bit and scans the folder the plug-in went into (on Windows, add %LOCALAPPDATA%\Programs\Common\VST3 to its VST3 folders), then rescan. If it still isn’t there, restart the DAW.

The plug-in window is blank (Linux)

Install WebKitGTK 4.1. On Debian or Ubuntu: sudo apt install libwebkit2gtk-4.1-0.

My Mac says it “can’t be opened”

You downloaded the zip in a web browser. Use the Terminal command instead, or run the xattr command in the download section.
