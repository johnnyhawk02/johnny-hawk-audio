Shyoy · free plug-in · beta

Install Shyoy

Shyoy is a monosynth modelled on the circuit of a classic 1980s single-oscillator analogue synth. The VCO, sub-oscillator, ladder-style filter, envelope and VCA run as circuit simulations using the original schematic values. The plug-in is VST3 for Mac (Apple Silicon and Intel), Windows and Linux, AU for Mac, and a standalone app. It is the same synth as the browser version: its output matches sample for sample.

Want to hear it first? It runs in Chrome or Edge, no install needed.

Play in the browser

New to Shyoy? Four pages on the panel, the sequencer and the randomiser.

Download and install

Download the zip for your computer, or copy the one-line install command and paste it into a terminal. The command downloads the newest build and puts the plug-in in the right folder.

Your computer

macOS

macOS 11 Big Sur or later · Apple Silicon and Intel · VST3, AU and app

Download zip, 20 MB

Install VST3 and AU together (Terminal)

cd /tmp && curl -fsSL -o Shyoy-macOS.zip https://github.com/johnnyhawk02/Sh101/releases/download/plugin-latest/Shyoy-macOS.zip && rm -rf Shyoy && unzip -q Shyoy-macOS.zip && mkdir -p ~/Library/Audio/Plug-Ins/VST3 ~/Library/Audio/Plug-Ins/Components && rm -rf ~/Library/Audio/Plug-Ins/VST3/Shyoy.vst3 ~/Library/Audio/Plug-Ins/Components/Shyoy.component && cp -R Shyoy/Shyoy.vst3 ~/Library/Audio/Plug-Ins/VST3/ && cp -R Shyoy/Shyoy.component ~/Library/Audio/Plug-Ins/Components/ && xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Shyoy.vst3 ~/Library/Audio/Plug-Ins/Components/Shyoy.component && echo "Shyoy installed"

Open Terminal (Cmd + Space, type Terminal), paste, press Return. It ends with “Shyoy installed”.

Optional: the standalone app (run after the line above)

cp -R /tmp/Shyoy/Shyoy.app /Applications/ && xattr -dr com.apple.quarantine /Applications/Shyoy.app

Your computer

Windows

Windows 10 or 11, 64-bit · VST3 and app

Download zip, 8.5 MB

Install the VST3 (PowerShell, as administrator)

curl.exe -fsSL -o "$env:TEMP\Shyoy-Windows.zip" https://github.com/johnnyhawk02/Sh101/releases/download/plugin-latest/Shyoy-Windows.zip; Expand-Archive -Force "$env:TEMP\Shyoy-Windows.zip" "$env:TEMP\Shyoy"; New-Item -ItemType Directory -Force "C:\Program Files\Common Files\VST3" | Out-Null; Remove-Item -Recurse -Force "C:\Program Files\Common Files\VST3\Shyoy.vst3" -ErrorAction SilentlyContinue; Copy-Item -Recurse "$env:TEMP\Shyoy\Shyoy\Shyoy.vst3" "C:\Program Files\Common Files\VST3\"; Write-Host "Shyoy installed"

Click Start, type PowerShell, right-click it and choose Run as administrator (the VST3 folder is in Program Files). Paste, press Enter. It ends with “Shyoy installed”. The standalone app is Shyoy.exe in %TEMP%\Shyoy\Shyoy\. You can copy it anywhere.

Your computer

Linux

x86-64 · VST3 and app

Download zip, 7.5 MB

Install the VST3 (terminal)

cd /tmp && curl -fsSL -o Shyoy-Linux.zip https://github.com/johnnyhawk02/Sh101/releases/download/plugin-latest/Shyoy-Linux.zip && rm -rf Shyoy && unzip -q Shyoy-Linux.zip && mkdir -p ~/.vst3 && rm -rf ~/.vst3/Shyoy.vst3 && cp -R Shyoy/Shyoy.vst3 ~/.vst3/ && echo "Shyoy installed"

Open a terminal (often Ctrl + Alt + T), paste with Ctrl + Shift + V, press Enter. It ends with “Shyoy installed”. The standalone app is /tmp/Shyoy/Shyoy-standalone.

Then rescan in your DAW

After installing, your music software has to rescan its plug-ins before it sees Shyoy. Put it on an instrument track.

  • Ableton LiveSettings > Plug-ins, turn on “Use VST3 Plug-in System Folders”, click Rescan.
  • Logic Pro / GarageBand(Mac) It appears under Audio Units. If not, restart Logic.
  • FL StudioOptions > Manage plugins > Find plugins.
  • ReaperOptions > Preferences > Plug-ins > VST > Re-scan.
  • Bitwig, Cubase, Studio One and othersRescan plug-ins or restart the DAW.

Installing by hand: unzip, then copy Shyoy.vst3 to the VST3 folder below. On a Mac, also copy Shyoy.component to the Components folder. Each zip has an INSTALL.txt.

  • macOS~/Library/Audio/Plug-Ins/VST3 and ~/Library/Audio/Plug-Ins/Components
  • WindowsC:\Program Files\Common Files\VST3
  • Linux~/.vst3

Unsigned builds

Shyoy isn’t signed by Apple or Microsoft, so your computer may warn you the first time. Here’s what to do.

macOS

The plug-in isn’t notarised by Apple. The Terminal line above already clears the quarantine flag. If you download the zip in a browser and copy the files by hand, run this in Terminal afterwards:

xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Shyoy.vst3 ~/Library/Audio/Plug-Ins/Components/Shyoy.component

Otherwise Logic or Ableton may say the plug-in “is damaged”.

Windows

Windows may warn that the plug-in is from an unknown publisher. For the app, click More info, then Run anyway.

The panel uses Microsoft Edge WebView2, which comes with Windows 10 and 11. If the window stays blank, install the “Evergreen WebView2 Runtime” from Microsoft.

Linux

The panel needs WebKitGTK 4.1 (or 4.0).

Debian / Ubuntu:

sudo apt install libwebkit2gtk-4.1-0

Fedora:

sudo dnf install webkit2gtk4.1

Arch:

sudo pacman -S webkit2gtk-4.1

What’s in it

  • VoiceVCO with saw, pulse with PWM, sub-oscillator and noise. A resonant filter that self-oscillates, ADSR envelope, VCA, LFO and portamento. Oversampling 1x, 2x or 4x (Options > Audio).
  • BenderVCO, VCF and LFO amounts, and octave transpose.
  • Sequencer16 steps with separate octave, gate, slide and accent lanes. Each lane has its own length, start and RETRIG, and there is a STEP CYCLE reset. Slides glide at the portamento time.
  • RecordRecord a note list that the gate lane plays through, with a loop length and note-per-gate or note-per-step advance.
  • RandomiseClick the shyoy logo for a new sound, at a level that matches the presets.
  • PresetsSave, rename, duplicate, delete, import and export. Each preset holds its pattern.
  • SlidersRight-click a slider to change its taper curve.
  • MIDINotes, pitch bend, mod, sustain, and CC 1–25 on the panel controls. In the web app a Bass Station II gets its own map. The web app needs Chrome or Edge on desktop for MIDI; other browsers play sound but have no MIDI.
  • In your DAWThe sequencer follows the DAW tempo and locks to its bar while playing, and each sound is saved with your project.

Updating and trouble

The download links always point to the newest build. To update, run the same install command again. Shyoy is a beta, so preset formats may change between versions.

Presets and options are shared by every Shyoy instance, and live in ~/Library/Shyoy (Mac), %APPDATA%\Shyoy (Windows) or ~/.config/Shyoy (Linux).

Nothing shows up in my DAW

Check the plug-in is in the folder listed above, then rescan. If it still isn’t there, restart the DAW.

My Mac says it “is damaged”

You downloaded the zip in a browser. Use the Terminal command instead, or run the xattr command in Unsigned builds.

The plug-in window is blank

On Windows, install the Evergreen WebView2 Runtime from Microsoft. On Linux, install WebKitGTK 4.1 (see above).
